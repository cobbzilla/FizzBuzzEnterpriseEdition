02 / Scope of this document

A charter, not a certification

These desks report the state of this running process. ISO 9000 and SOC 2 controls remain open. The recovery drill verifies a stored copy at one instant; it does not restore a backup. The API guide describes the implementation in the deployed revision shown on the main showcase.
