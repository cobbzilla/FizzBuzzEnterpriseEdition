# ADR 0042: Unauthorized Approval Transportation

Status: accepted, 10 November 2026.

Emoji companions can steal the notary's illustrated stamp during Executive
Hovering. A live encounter must be a multi-digit decimal palindrome, be disclosed
by the current mandate, and have an actual Java companion assignment. At most
three incidents occur per mandate, shared with paper aviation and separated by
at least thirty ordinals. The common incident lease prevents overlapping flights
and chases. With the
ordinary sequence, the first opportunity is 33. Companions and heists must both
be enabled. Ordinary immediate reading and retained replay do not introduce
new automatic incidents.

## One stamp, excessive custody

The first suspect is the appointed companion. Up to two distinct, previously
disclosed companions from the same mandate and authority join it. A versioned
seed binds the mandate, ordinal, allocation authority, source and ordered cast
to three distinct destination departments. Scenes resolve symbolic room addresses
against the current estate, including reorganized estates. This is fictional
presentation; it does not change Java decisions, notarial seals, rarity weights,
companions, caches or audit entries.

Three five-second escape legs transfer the stamp between the cast, followed by
a three-second return. A visitor can intercept the actual holder, accuse an
innocent suspect and receive an alibi, expose footprints, offer a biscuit, or
skip the chase. Correct interception and amnesty show the return before releasing
the hold. Unattended suspects automatically return the stamp. Buttons provide
the same interventions as native object picking. All inputs are guarded against
stale chase generations and repeated recovery.

Snails accelerate from an exceptionally slow start. Ghosts travel directly
through walls while pursuing paperwork follows corridors. Octopuses display
seven additional counterfeit stamps. The actual stamp remains a single logical
object. Other companions use the ordinary escape choreography.

Facilities provides a deliberate rehearsal with snail, ghost and octopus
ringleaders. The ghost is a named visiting security stand-in, because the
nonhuman companion catalogue excludes faces. Rehearsals are clearly labeled,
award no discoveries, and can run without a numerical mandate. They are never
used to introduce a rare companion into the discovery register.

## Interruption and continuity

The chase supplies a separate hold, leaving the user's Pause setting untouched.
Observation clocks, final acknowledgments and ordinary line disclosure all
respect it. A successful return releases only that hold. Stop, replacement,
Autonomy, closing Facilities and disabling mischief settle the stamp immediately.
Replays and new mandates invalidate earlier pursuit callbacks.

Reorganization has priority: the chase clock freezes while the departments move,
then its route resolves against their new addresses. The interrupted production
decision retains its prior elapsed time and at-most-once publication boundary.
Java computation has already completed for a bounded mandate; the held operation
is its visible disclosure, not an in-flight Java transaction.

Navigation, hidden canvases and background tabs do not strand a chase. A timer
witness supplements animation callbacks, as in the existing presentation clock.
Reduced motion uses stationary characters and an estate overview; graphics
refusal retains the named suspect controls and readable incident report. The
controls move with their existing stage into full-screen. Keyboard focus returns
to the available office control when the chase ends.

The tab remembers its opt-out. Normal application refresh resets that preference.
Ten bounded incident records remain available in Facilities. The optional GPU
module receives snapshots from the single demo owner; it has no second mutable
coordinator. Three sprites, eight stamp models, twelve footprints and three
sheets are allocated only when the first chase is shown, then reused, with
replaced emoji textures disposed. Ordinary office visits retain their existing
mesh budget.
