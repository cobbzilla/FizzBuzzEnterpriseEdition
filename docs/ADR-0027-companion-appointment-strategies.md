# ADR 0027: Deterministic, interchangeable companion appointment policies

Date: 2026-11-02. Status: accepted within the selected companion iteration.

`EmojiAssignmentStrategy` supplies versioned appointment policies. Factor Resonance incorporates the exact ordinal, flavor and bounded factor evidence; Ordinal Constellation uses the ordinal and flavor independently of factor evidence. Both use the same weighted catalog. `FactorProfileOffice` and `EmojiCatalog` are separately replaceable. Spring injects the actual providers into `CompanionDirectorate`, and `HttpMain` passes that bean to the HTTP dispatcher. The browser explicitly assembles these same Java implementations for TeaVM. TypeScript controls presentation and never reimplements factorization or assignment.

The immutable TypeScript authority, `catalog/bestiary.ts`, contains 3,200 characters: 1,364 admitted single Unicode emoji and 1,836 themed pairs. Every single has an individual story seed; paired dossiers extend that specific history with an edited, department-appropriate second career, new energy and new ambition. Pairs are identified as pairs, rather than claimed as new Unicode glyphs. The Unicode 18.0 snapshot and license are retained under `data/unicode/`. Both Java artifacts include the license resource; the static and server sites serve `/unicode-license.txt`, linked from the bestiary and available offline. People, human faces, gestures, skin-tone aliases and flags depicting human figures are excluded. The generator emits checked-in Java chunks of 24 records and verifies them against the canonical constants during release.

Exactly one billion positive integer tickets implement the scarcity charter:

| Tier | Characters | Tickets | Share |

| Common | 320 | 800,000,000 | 80% |
| Uncommon | 1,920 | 190,000,000 | 19% |

Common characters each have 2,500,000 tickets; Legendary characters have 74 each. Mythic weights are 1 through 32, beginning with unicorn, phoenix and dragon. The rarest target frequency is one in a billion; every character in the rarest 1% is rarer than one in a million. A fixed 64-bit hash and avalanche mix map versioned seeds into the inventory. These are allocation weights across deterministic inputs, not guarantees for any finite input range; modulo reduction has negligible finite-hash bias. This hash is not a security primitive. Revisiting an ordinal is not another draw. The eleven single-symbol Mythics are excluded from all pairs, so a common paired appointment cannot bypass their scarcity.

The factor office extracts primes through 97 within 128 division attempts. A residual is proved prime only if previous trial divisions establish that it is smaller than the next untested prime squared. Otherwise its exact value remains explicitly unresolved. Budget exhaustion can leave further copies of an extracted prime in the cofactor; the public field therefore describes extracted factors rather than necessarily complete multiplicities. Every positive exact ordinal still receives its eligible assignment without unbounded factorization.

Catalog, strategy and finite assignment-window endpoints are read-only. They create no audit entries or numerical output and are admitted to release-local browser execution alongside older persistent owners. The client batches 100-ordinal inspections, retains the latest 1,000 disclosed ordinals and renders at most 100 encounters. Toggle, policy changes and replay never repeat numerical production. Reading older encounters suspends automatic following.

The public bestiary has search, format/category/rarity filters and pagination. The unlisted `/department-of-improbable-appointments/` shows every character in descending ticket-weight order without pagination and includes `noindex,nofollow`; discoverability is not an authorization boundary. Mobile submissions reveal Official output while respecting reduced motion. Textual names accompany decorative glyphs, and native story dialogs restore focus to their initiating controls.

Story dialogs keep an explicitly labelled X in a fixed top-right toolbar while the named biography region scrolls independently. A pointer gesture beginning and ending on the backdrop dismisses the dialog; selecting text inside and releasing outside leaves it open. X, backdrop and native Escape closure restore the initiating companion's focus. New biographies start at the top, including after an earlier dossier was scrolled. Long ordinal headings remain in the scrolling body so they cannot displace the exit.

Validation covers all character and ticket boundaries, factor reconstruction, unresolved enormous cofactors, actual Spring wiring, independent provider substitutions, golden assignments, sampled frequencies, concurrent isolation, HTTP rejection, unchanged output and audit state, JVM/TeaVM parity, both browser engines, offline availability, mobile positioning, reading-position retention and accessibility. Mobile dismissal checks exercise touch, the fixed close control, long biographies, preserved text-selection gestures and focus restoration in all three browsers.
