# ADR 0031: Executive Hovering: Trust Has Been Suspended

Status: accepted, 3 November 2026.

The Companion Roll Call receives its own visibility preference, initially on.
Hiding attendance minutes does not suspend companion allocation or discoveries.
The separate existing allocation checkbox retains that authority.

An initially disabled executive-observation preference adds a compact office
view directly beneath Official Output and above attendance. It temporarily
owns the disclosure-cadence selector through an otherwise absent, disabled
option. Leaving the mode restores the visitor's preceding ordinary cadence.

The supervisor consumes the same actual Java dossiers as the Chronicle. It
replays every supplied event in order rather than reducing a line to a room
summary. A fresh fifteen-number dossier currently contains 436 events. The
scene determines the disclosure clock: arrival, work and a reading hold finish
before the next event begins. Publication releases its line when the pictured
printer finishes, then audit, queueing, commit, release and succession continue.
No independent per-line timer runs in this mode. Java production still finishes
before this presentation begins; elapsed-service measurements retain that fact.

Reception, both boundary votes, seven recruitment approvals, vacancy surveys,
identified hidden tenants, eviction, leases, individually certified glyphs,
assembly, notarial inspection, printing, hash-linked minutes, mailbox enqueue,
transaction completion, cleanup and succession receive physical presentations.
Authored camera shots approach the workbench, pull back for room transfers,
and hold on each action. The stage geometry illustrates records rather than
claiming that Java actually ran inside a model office.

Cache hits show their supplied reuse proceedings and retained-text disclosure;
they invent no new workforce, letter purchases or audit entries. Legacy and
truncated dossiers identify missing evidence rather than reconstruct it. Zero
and terminal boundary refusals have no imaginary numerical output. Extended
mandates remain finite windows; exact decimal strings are never converted to
unsafe floating-point ordinals for presentation.

Pause, one-decision stepping, Stop, revealing output, mode changes, newer
mandates, retained replay and personnel rehearsals share explicit cancellation
and ownership rules. Each publication callback runs at most once. As amended by
[ADR 0036](ADR-0036-continuous-mobile-playback.md), off-screen, background and
obscured views continue advancing unless explicitly paused. GPU visibility is
independent of disclosure. Reduced motion uses stationary
shots with the same readable sequence. A graphics failure keeps a semantic
evidence presentation and the same functioning controls.

The existing estate tour remains independent and lazy. Both presentations use
the same bundled Babylon implementation through its renderer interface, with
bounded scene objects and only visible scenes rendering. The supervisor adds
no production API, storage schema or mathematical implementation. Companion
cameos and discoveries remain limited to actually disclosed appointments.

Verification covers evidence ordering and omission, repeated glyph identities,
publication timing, clock pause/step/cancellation, cache and zero truthfulness,
legacy fallback, exact large ordinals, live mode changes, optional attendance,
output/scene co-visibility, real 3D camera/activity, keyboard and narrow reflow,
offline and Java modes, and the normal complete release gates.
