# ADR 0004: SlopFizzBuzz brand jurisdiction

## Status

Approved by the naming committee after review of 98 affected paths.

## Decision

Project coordinates, Java package names, public types, factories, strategy
names, method names, Spring bean names, and test names use SlopFizzBuzz.
The original FizzBuzz rules remain the external output contract: the fifteenth
line still says `FizzBuzz`.

The project therefore distinguishes the name of the institution from the
answer it is chartered to produce. Renaming either one requires a separate
decision record and a full one-to-one-hundred regression run.
