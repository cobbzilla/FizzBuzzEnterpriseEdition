# ADR 0040: Adjustable cadence with render-aware office progress

Authorize and Observe retain the same four enabled cadence choices with or
without Executive Hovering. The mode no longer inserts or selects a disabled
synthetic cadence. Leaving supervision keeps the selected authority. A live
change changes the next clock increment; it does not replace the current
decision, rewind a phase, clear a pause, or repeat any Java operation.

Office rates are explicit: Full Board Ratification advances authored time at
one half of Interdepartmental Sign-Off, which retains the existing choreography.
Emergency Delegated Authority advances it at twice that rate. The ordinary
line-reading values remain compatible with stored preferences. Executive Fiat
adds no discretionary delay, while retaining enough actual frames to show travel,
work and a final disclosure. Its speed is bounded by what the renderer paints.

The renderer reports completed frames, the cue actually drawn, frame intervals
and render cost. While the office is visible and ready, the observation clock
uses those completed-frame timestamps. Repeated scheduler callbacks for one
paint earn no extra progress. Each increment is limited to its current phase;
travel also receives a sample budget based on route length, angle and zoom.
Delayed callbacks therefore stretch visible choreography rather than skipping
directly through arrival, work and publication. The final rendered cue must be
acknowledged before the next automatic decision; numerical output follows its
actually painted printing work. An explicit Next retains its one-decision scope.

An exponentially smoothed frame/cost governor selects the existing economy
rendering mode after sustained pressure. This lowers resolution and shadows;
recovery requires a long stable interval to avoid quality flicker. It does not
change evidence, output, event ordering, companions or numerical execution.
Reduced motion retains stationary shots. Background observation, an unavailable
GPU and loading graphics continue through the timer/semantic path without
silently pausing the run. A hidden or failed canvas does not claim rendering
authority. No device fingerprint or benchmark leaves the browser.
Scene disposal attempts engine disposal even if a scene cleanup throws. A lost
renderer is detached before its cleanup, so an adapter's disposal error cannot
strand logical progress or re-enter the same failing renderer.

Validation includes rate ratios, phase boundaries, large delays, repeated frame
timestamps, cadence changes during pauses, background progress and quality
hysteresis. Browser checks use genuine completed-paint observations and a
cancelable, delayed animation-frame driver with an injected stall. They check
bounded camera/work progress and publication after paint. Graphics-refusal
injection blocks service workers so a cached module cannot invalidate the fault.
Existing supervision, mobile, fullscreen, reorganization, output and audit checks
remain part of the normal serial release gate.
