# ADR 0029: Mandate-seeded appointments and the extraordinary register

The exact canonical mandate upper limit is additional deterministic input to
companion assignment. Java still owns allocation in both server and browser
compilers. Both swappable strategy providers remain injected through their
existing interface. The directorate composes the provider's original ticket
with `mandate-v1|catalogVersion|strategy|mandate|ordinal|flavor|originalTicket`,
using the existing fixed 64-bit ticket hash. This is reproducible exploration,
not a security primitive, lottery, or promise that distinct seeds cannot collide.
The billion-ticket catalog and all rarity weights are unchanged.

`GET /companions/window?start=1&count=15&strategy=factor-resonance-v1&seed=15`
returns v2, echoes canonical `mandateSeed` and `seedPolicy: mandate-v1`.
Omitting seed preserves the old v1 schema and golden assignments. Zero and
arbitrarily long exact decimal seeds are valid. Negative, encoded, duplicate
or malformed parameters are rejected. The UI keys batches by seed as well as
authority and ordinal, checks echoed evidence, and rejects late generations.
An unsubmitted edit does not change the seed of already disclosed output.
Replay uses the retained mandate. Policy changes do not repeat numerical work.

The five rarest distinct disclosed companions are saved in localStorage under
`slopbuzz:extraordinary-appointments:v1`, separately from the audited numerical
repository. Smaller ticket weights rank first. Catalog version plus companion
identifier defines identity; equal weights sort by identity. The first encounter
retains exact mandate, ordinal, authority, catalog, ticket and factor evidence,
plus the full dossier. Top-five union merging converges across concurrent tabs.
Malformed persisted records are ignored. Storage failure retains session finds
and reports the limitation. No input, seed, dossier or share query is sent to
analytics. Prefetched ordinals do not count as discoveries.

A shared footer component displays the collection on every page. Its measured
height reserves document space. Focused chips and open biographies defer
replacement until the reader asks for the latest finds. One shared modal keeps
the visible close control, backdrop dismissal, Escape and opener focus return.
Reading-only pages display the saved dossiers without starting Java.

Encounter links retain exact seed, ordinal, authority and catalog. They prefill
controls without auto-running a possibly enormous mandate. Explicit referral
inspection asks the Java authority to reproduce exactly one encounter and
verifies all provenance before opening its story. Such inspection does not
print numbers or fabricate a discovery. Only actual disclosed output enters
the register. Browser storage is local, editable and clearable; it is a souvenir,
not evidence of competitive achievement or numerical audit custody.
