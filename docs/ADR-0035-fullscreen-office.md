# ADR 0035: Full-screen office presentation with retained ownership

Facilities exploration and Executive Hovering share one TypeScript presentation
controller. It opens a native modal dialog whose non-dialog inner surface is
the Fullscreen API target. The browser request runs inside the initiating button
gesture. Unsupported or rejected requests leave the same viewport-filling
dialog usable. We listen for external native full-screen exit and restore the
website. We do not lock Escape or force an orientation.

The controller relocates existing canvases, controls and evidence using marked
return positions. It never creates another renderer, run, repository owner or
business operation. The Chronicle moves through its existing placement API,
preserving its reading/follow state. Closing the presentation restores the same
elements, focus and page position. Desk navigation restores elements before
changing the workspace; disabling supervision returns to the visible preference
when its former full-screen launcher is no longer available.

Observe keeps output and the running Chronicle near opposite lower corners.
Its current recorded decision remains above the log, and a compact companion
can open the existing biography dialog. Playback and live settings retain their
original handlers. Small layouts initially show one evidence panel; enlarged
text starts with panels hidden and a horizontally scrollable control strip.
The selector offers both, either, or neither. The building fills the
viewport in every case. Facilities exposes camera and route controls at the
bottom, with its full directory, stories, route, preferences and arrangement
records in a bounded drawer. Picking an object reveals its existing story.

The full-screen presentation is an active office view, rather than a reason to
pause observation or the moving ceremony. Other dialogs still pause business
disclosure. Biography and personnel dialogs move within the native full-screen
surface so they remain available above the building. The real run/tour status
announcer also moves into the modal as a visible, bounded line above its controls.
Resize observers resize the retained Babylon engines. Existing reduced-motion,
graphics-failure, offline and audit contracts apply unchanged.

Validation covers a refused native request, actual browser full-screen and
external exit where supported, enlarged-modal entry, picking, walking, exact
publication, audit custody, reader position, live preference changes, nested
biographies, navigation, narrow/short screens, enlarged text, accessibility and
graphics refusal. Browser jobs run serially.

API references: [requestFullscreen](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)
and [fullscreenchange](https://developer.mozilla.org/en-US/docs/Web/API/Document/fullscreenchange_event).
